# programming_practice

カスタマーエンジニアを目指して取り組んでいる、自己学習の記録です。

## 主な内容
- **linux-build-practice**：VirtualBox上のUbuntu Serverで、cronの設定、Apacheの構築、障害対応の手順書作成を実践
- **Linux_study**：LPIC 101に向けたLinux学習のメモ
- **Java_practice**：「スッキリわかるJava入門」を使った基礎学習（タスク管理アプリ・家計簿アプリなど）
- **python_practice**：Pythonの基礎と、Webスクレイピング・PDF操作・画像処理などの練習
- **SQL_study**：SQLの基礎（SELECT文から学習中）
- **Excel_study**：Excel関数の練習問題
- **claude_code_practice**：生成AI（Claude Code）を活用した開発の練習
